# Paste by Keyboard

### A simple script for pasting in no-clipboard applications using your keyboard.

## **How to use**

- Unpack the distribution and run the executable
- Use `F12` to paste
- Use `ctrl` + `shift` + `Q` to exit
- (optional) Make a shortcut for `Paste by Keyboard.exe`

_You can edit the paste hotkey and the delay in which individual letters are being pasted in `settings.ini`_
